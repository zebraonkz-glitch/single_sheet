# Складской учёт (офлайн)

Десктопное приложение на **Python + SQLite + PyQt6** для учёта товаров на одном листе (аналог Excel). Работает без интернета.

## Возможности

- Учёт по складу (А/Б) и дате, номенклатура всегда на экране
- Авторасчёт «Остаток на конец», валидация чисел, автосохранение
- Диалог парного перемещения между складами
- Ежедневный ZIP-бэкап БД при закрытии
- Отчёты: движение товаров / актуальные остатки → PDF

## Структура папок

| Путь | Назначение |
|------|------------|
| `main.py` | Окно приложения |
| `database.py` | SQLite CRUD и отчёты |
| `pdf_generator.py` | PDF (fpdf2) |
| `archiver.py` | Ежедневный ZIP |
| `app_paths.py` | Пути (в exe — рядом с .exe) |
| `config.json` | Склады, пути, дата бэкапа |
| `db/inventory.db` | База данных |
| `backups/` | `backup_YYYY-MM-DD.zip` |
| `reports/` | PDF-отчёты |
| `../shablon/` | Excel-шаблон номенклатуры (колонка B — наименование) |

В сборке exe шаблон лежит в `shablon\` рядом с exe.

## Шаблон номенклатуры (только первый запуск)

Excel в `shablon/` нужен **один раз** — при пустом каталоге в БД имена импортируются в таблицу `nomenclature`.

Дальше приложение **не читает** шаблон:
- список позиций берётся из БД;
- новые строки добавляются в каталог при сохранении;
- удаление строки убирает позицию из каталога.

Файл xlsx после первичного импорта можно не держать рядом с программой (для новой чистой БД он снова понадобится).

1. Положите `.xlsx` в `shablon` (колонка B — наименование, со 2-й строки).
2. Запустите приложение — каталог заполнится.
3. Ведите учёт без привязки к Excel.

## Очистка архивов

При каждом закрытии приложения сегодняшний ZIP (`backup_YYYY-MM-DD.zip`)
**перезаписывается** актуальным состоянием БД. Хранятся не более **7** последних
дневных копий — более старые удаляются.
