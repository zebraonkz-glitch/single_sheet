## 1. Цели и границы

### Делаем
- Десктоп на PyQt6, полностью офлайн
- SQLite (`db/inventory.db`)
- Основной лист учёта: склад + дата + таблица из 9 колонок
- Авторасчёт `final_stock`
- Вкладка отчётов + экспорт PDF (`fpdf2`)
- Ежедневный ZIP-бэкап БД при закрытии
- Загрузка начальной номенклатуры из `shablon/`

### Не делаем (в первой версии)
- Сеть / синхронизация / облако
- Более двух складов (только А и Б по `config.json`)
- Автоочистка старых бэкапов (только инструкция в README)
- Полноценный учёт партий / серий / единиц измерения

## 2. Ключевые решения до кода

1. **Формула остатка**  
   `final_stock = initial_stock + incoming + move_stock - (consumption_1 + consumption_2 + consumption_3)`  
   Считать в Python (и при желании дублировать GENERATED в SQLite, если версия поддерживает).

2. **Перемещения**  
   При вводе `move_stock` — диалог: создать парную запись на другом складе с противоположным знаком (опционально).

3. **Сохранение**  
   Автосохранение при изменении ячейки + кнопка «Сохранить всё» как страховка.

4. **Номенклатура**  
   При отсутствии данных на выбранную дату/склад — показать все позиции из шаблона с нулевыми движениями.

5. **Пути**  
   Относительно корня приложения: `db/`, `backups/`, `reports/`, `config.json`, `shablon/`.

### Этап 2. База данных (`database.py`)
**Результат:** CRUD и фильтрация по складу/дате.

- [x] Подключение к `db/inventory.db`, создание БД при отсутствии
- [x] Таблица `operations` + индекс `(warehouse_id, operation_date)`
- [x] Методы: `get_data(warehouse_id, date)`, `save_row(...)`, `delete_row(id)`, `upsert` при автосохранении
- [x] Транзакции (`BEGIN` / `COMMIT`) для пакетного сохранения
- [x] Загрузка списка наименований из `shablon/*.xlsx`
- [x] При пустой выборке — вернуть шаблонные строки с нулями **без INSERT** (`id=None` до первого `upsert`/`save_row`)

**SQL-схема (ориентир):**

```sql
CREATE TABLE IF NOT EXISTS operations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    item_name TEXT NOT NULL,
    initial_stock REAL DEFAULT 0,
    incoming REAL DEFAULT 0,
    move_stock REAL DEFAULT 0,
    consumption_1 REAL DEFAULT 0,
    consumption_2 REAL DEFAULT 0,
    consumption_3 REAL DEFAULT 0,
    final_stock REAL,
    warehouse_id TEXT NOT NULL,
    operation_date DATE NOT NULL
);
CREATE INDEX idx_warehouse_date ON operations(warehouse_id, operation_date);
```

**Критерий:** модуль можно проверить отдельно (простые вызовы insert/get/delete).
